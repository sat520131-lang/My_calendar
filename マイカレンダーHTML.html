Googleカレンダー連携

ブラウザから直接Googleカレンダーにつなぎます。予定データがこのアプリのサーバーに送られることはありません。

初回だけ必要な設定（Google Cloud）

  1. Google Cloud Consoleでプロジェクトを作成（既存でもOK）
  2. 「APIとサービス → ライブラリ」で Google Calendar API を有効化
  3. 「OAuth同意画面」を設定（外部・アプリ名は任意）
  4. 「認証情報 → 認証情報を作成 → OAuthクライアントID」で種類「ウェブアプリケーション」を作成
  5. 「承認済みのJavaScript生成元」に、このページをブラウザで開いたときのアドレス（ドメイン部分まで）を追加
  6. 発行されたクライアントIDを下に貼り付けて「保存して接続」

表示するカレンダーと色

カレンダーの色

四角いチップはGoogleカレンダー側の色です。色はこのアプリ内の表示にだけ使われます。

ホーム画面に追加

iPhone（Safari）: 共有ボタン →「ホーム画面に追加」。Android（Chrome）: メニュー →「ホーム画面に追加」。アイコンから直接このカレンダーを開けるようになります。
